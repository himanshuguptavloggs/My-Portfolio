## 📝 What to Edit

### To Customize Content:
- Edit `index.html` directly

### To Change Colors:
- Edit `css/styles.css` `:root` section

### To Change Animations:
- Edit `css/styles.css` `@keyframes` section
- Edit `js/script.js` animation functions

### To Change Form Function:
- Edit `js/script.js` `simulateFormSubmission` function

### To Add Images:
- Add files to `assets/` folder
- Update paths in `index.html`

## 💡 Pro Customization Tips

1. **Use Find & Replace** in your editor
   - Find: "Sagar Rathore"
   - Replace with: "Your Name"

2. **Color Theme Changer**
   - Change only 3 variables in CSS
   - Entire site updates!

3. **Copy-Paste Projects**
   - Duplicate one project card
   - Update the content
   - Repeat 6 times

4. **Icon Finder**
   - Search Font Awesome icons
   - Use icon names in HTML

5. **Use Browser DevTools**
   - Right-click → Inspect
   - Preview changes in real-time
   - Copy code snippets
